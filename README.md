# antd-react

This project is initialized with `pro create`. Follow is the quick guide for how to use.

## Environment Prepare

Install `node_modules`:

```bash
pnpm install
```

## Provided Scripts

antd-react provides some useful script to help you quick start and build with web project, code style check and test.

Scripts provided in `package.json`. It's safe to modify or add additional script:

### Start project

```bash
pnpm start
```

### Build project

```bash
pnpm run build
```

### Check code style

```bash
pnpm run lint
```

You can also use script to auto fix some lint error:

```bash
pnpm run lint:fix
```

### Test code

```bash
pnpm test
```
